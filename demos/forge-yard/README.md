# Forge Yard · original Wildshard combat demo

A standalone local browser prototype. The original Walker model has eighteen articulated joints; it drives locomotion, reaction, three shared weapon styles, and three signature attacks. Its `grip_R` socket carries the chosen weapon. Walker can equip the twelve tracked Wildshard weapon GLBs and face twenty differently rigged opponents. The original four use a sweep, pounce, beam and charge. Hook Crane pulls the player, Kiln Warden blocks frontal hits and shoves, Breakwater Snare emerges at a marked point, and Spark Buoy bursts in a radius. The ordnance group adds a locked three-pulse salvo, a committed blade lunge, a visible lob into a marked impact zone, and a transverse sweep. The foundry line adds a cone pull and release, alternating cut marks, two flank pylons with a safe seam, and a jet with reverse recoil. The terminal line adds a shutter opening, a three-pocket trail, a rotating beam, and a lateral strike at the old mark. The fitted three-quarter camera keeps world-relative stick directions. The browser uses their exported state clips and the original weapon attack clips. This is not a Wildshard production build and it uses no Fable content or code.

From a checkout of the art branch:

```sh
cd demos/forge-yard
npm ci
npm run build
npm test
cd ../..
python -m http.server 5187
```

Open `http://127.0.0.1:5187/demos/forge-yard/`. Drag the left stick or press WASD to move. Use the two lower-right buttons (or Space and Shift) to attack and dodge. Change weapons with the selector and use the Rival dropdown or Next rival to load another opponent. Select Base type or one of five variant kits: Rusher (short sprint), Bulwark (frontal armor), Feinter (false tell and sidestep), Echo (retargeted follow-up), and Overload (timed radial discharge). Each alters the same base type’s fight and adds visible equipment, not simply dye.

For reproducibility the three dependencies are pinned; the generated viewer bundle and dependency tree are not checked into Git. Optional browser smoke: `npx playwright install chromium` then `npm run test:browser -- http://127.0.0.1:5187/demos/forge-yard/ /tmp/forge-yard-proof` from this directory with the server running. The condition-driven touch runner fights each rival, checks the Defeat pose and strikes with all twelve distinct weapon GLBs, and checks that each of the 100 variant selections mounts geometry in the browser. The simulation suite checks all 100 behavior combinations. Full-win browser evidence covers base types with Rivet Maul, not a full fight against every variant; see browser-proof.json for the recorded run. Browser QA is not a physical phone acceptance test.

Startup fetches the first rival and equipped weapon together. Other rival GLBs are fetched when selected and cached for later rematches; a failed next-rival load leaves the current fight in place and can be retried. For a cache-disabled synthetic portrait startup check, run `node demos/forge-yard/startup-smoke.mjs http://127.0.0.1:5187/demos/forge-yard/ lazy` from the repository root. The sample uses 450,000 B/s download and 80 ms latency. See `startup-proof.json` for the matched eager and on-demand receipts.

Run `node demos/forge-yard/walker-smoke.mjs http://127.0.0.1:5187/demos/forge-yard/ /tmp/walker-proof` from the repository root to verify actual browser playback of all twelve Walker clips, plus motion of the attached right-hand weapon socket. This is not per-frame weapon or enemy contact collision.

The authored foundry set in `foundry-dressing.mjs` generates all its surface textures and batches repeated fixture parts. It is visual only: `arena.mjs` still owns the movement boundary and four collision discs. `dressing-smoke.mjs` captures portrait and wide browser views and can compare an independently served baseline supplied as the third optional argument.

The original style trails read the authored grip/tip sockets. The impact cue follows the simulation-confirmed hit and uses a bounded near-side art anchor, not blade collision. Run `node demos/forge-yard/impact-smoke.mjs http://127.0.0.1:5187/demos/forge-yard/ /tmp/impact-proof` to capture three style hits and a reduced shield hit.

Scope: first-pass yard layout and an original rigged Walker character, no progression, multiplayer or campaign. One hundred variants reuse twenty base rigs, not one hundred separate models. The standard enemy Move/Windup/Attack/Recover/Hit/Defeat clips are wired; Salt Mortar, Lantern Relay, Porcelain Seeder and Keel Crab use Special for their active attacks. During pursuit the renderer blends the authored Turn clip on stronger heading changes, using yard-owned yaw rather than adding the baked root swivel. The Echo variant uses the authored Special clip on its retargeted follow-up; the short Windup and combat rules are unchanged. Attacking rigs face the current attack lock. See `enemy-motion-proof.json` or run `node demos/forge-yard/enemy-motion-smoke.mjs` from the root with the server running to check these paths on Gate Sentry.

The duel camera uses a 24° fixed tilt and fits conservative body bounds for both fighters at the current aspect ratio. It backs out immediately when the bounds grow, then eases back in. The stick stays world-relative. This is geometric framing, not occlusion detection: scenery or an extended weapon can still cross the view. Run `node demos/forge-yard/duel-camera-smoke.mjs` from the repository root with the server running to verify framing, a Sentry hit and a Ballast Ram windup and dodge in portrait and landscape.

The base Ballast Ram is vulnerable for 0.88 seconds when its charge does not damage Walker. The cyan ground ring counts down that opening; one confirmed in-range attack gets a 35% damage bonus (rounded up) and closes it. A charge that deals damage never opens the counter. Variants are intentionally unchanged. Run `node demos/forge-yard/ram-counter-smoke.mjs` with the yard served to reproduce the touch counter.

Beacon Lance blends its visual shaft toward the rival’s weak-point socket during the thrust, around the existing authored grip point. This is directional and does not extend the weapon or modify the simulation’s attack test. The portrait `thrust-alignment-smoke.mjs` checks the first rendered counter frame and shows the angle before and after the corrective pivot and any measured grip drift.

The night-shift lighting pass lowers broad fill and uses the yard’s existing two point lights for warmer furnace-side and cooler service-side tones. Three tiny generated additive floor pools sit below the combat decals; the two recessed light grates are decorative. It adds no shadow map, bloom pass, new realtime light, or collision primitive. `foundry-lighting-proof.json` records the old/new touch and new counter smoke.

Gate Sentry’s sweep paints its exact distance threshold on the floor, uses an amber clock to show windup time left, and briefly holds the edge after release. Cover and the dodge window still apply behind or inside the edge; it is a distance cue, not a collision preview. Its radius comes from the same function as the damage check. With the yard served, use `node demos/forge-yard/sentry-sweep-smoke.mjs` for portrait touch cases just inside and outside that line. Simulation tests also hold the player 5 mm either side and behind cover.

Add `?arena=breakwater` to the same local URL for **Signal Breakwater**, an original outdoor layout study with a signal lantern, seawall, kelp-grey aggregate deck, offshore rocks and four differently modeled cover silhouettes. The deck, water, fixtures, and sky are generated from editable source in `breakwater-dressing.mjs`; no downloaded art textures or extra asset packages are required. It shares Forge Yard’s combat layout, bots, movement limits, and cover collision, and keeps the offshore sea as scenery. Run `duel-camera-smoke.mjs` with that full URL to check Sentry and Ram on both portrait and wide touch views.

Signal Breakwater’s marked side channel flashes for 1.25 seconds before a moving wash crosses it. Stay out of the blue strip, or leave it on warning; contact deals 12 damage once per wave. The player’s ordinary dodge immunity still applies, and the tide does not damage enemies. Forge Yard has no tide. The flush channel, countdown, visible wash and collision share the same dimensions; run `breakwater-surge-smoke.mjs` with the local Breakwater URL and an output directory to reproduce the portrait touch trials.

Rivet Maul, Slipfin, and Rail Needle use Walker’s original MaulDrop, SlipfinRip, and NeedleJab clips. All twelve weapons scrub their Walker body clip around its authored frame 15 on the actual release tick. This changes body animation timing, not hit geometry or damage. Use `walker-strike-smoke.mjs` with the yard URL and output directory for the twelve-weapon portrait confirmation and three sets of true windup/impact frames.

Line Pike and Rail Needle now use the grip-pivot aiming curve during their thrust. Their target is the rival-facing visual impact anchor, while Beacon Lance retains its existing weak-point aim. The shaft keeps its length, and neither combat reach nor damage changes. `thrust-roster-smoke.mjs` reports the first rendered hit frame, residual angle, grip slip and remaining tip-to-anchor distance separately. This is a presentation correction, not contact collision.
