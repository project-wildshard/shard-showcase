# E11c: from the Foreman floor through G3 into Titan Lane

The new apron fills the common-grade crossing between the tested 28 m-radius C3 floor and the existing G3 passage slab at X188. It matches the polygon edge on the court side and flares from 6.00 to 7.68 m inside the opening. Both seams remain at Y=0.05 m, with 41 probe locations per seam confirming the opposing source and apron spans do not overlap or leave a gap at the tested points. Sparse trim stays decorative.

The 5,216-byte GLB is 52 triangles and goes at Three (146,0,186) at identity, alongside the fitted Court 3 floor. The existing G3 junction goes at (198,0,186). For this combined fixture only, omit its named `C3 exact eastern fight floor` mesh; the r28 floor already occupies the same space. Use the prior G2 threshold and office placements, unchanged. G3 rails, frame, turn, sign and underlying yard slab remain from the original G3 donor. No source GLB is edited.

The stock capsule walked from the G2 threshold across Court 3, through the open G3 frame, turned into Titan Lane and walked back on all five runs (approximately 239–243 m per round trip). None jumped, stalled or became airborne. In the matching outbound control without the apron the capsule could still get through, but dropped about 5 cm onto the source yard datum for 196 ticks. The new piece removes the grade dip; it does **not** unlock a gate. The cyan line in the renders is measured motion, not part of the asset.

This is a movement/geometry bench. No encounter, portal transition, Titan plaza visit, live doors, or iPhone playtest.

```sh
D=demos/native-c3-g3
T=/tmp/c3-g3
A="$PWD/public/assets/wildshard-art"
blender -b -t 8 --factory-startup --python-exit-code 1 --python "$D/build.py" -- "$A" "$T"
node --experimental-transform-types "$D/sample.mjs" "$T"
blender -b -t 12 --factory-startup --python-exit-code 1 --python "$D/build.py" -- "$A" "$T" "$T/walk.json"
```

Run from the repository root with Engine 0.1.44 installed, or set `WSC_NODE_PROJECT` to the pinned project. The base geometry is regenerated by the exact [C3 floor build](../native-c3-floor/README.md). See [the receipt](../../project/layouts/e11c-c3-g3-apron-proof.json).
