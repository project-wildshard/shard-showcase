# The shared brief, rewritten

The brief had grown by accretion over one afternoon: an art bullet,
then a camera bullet, then HUD, desktop, test phone and git lines.
Several bullets said the same thing about the look, and "AAA" appeared
four times.

- An Opus agent working from a clean context regrouped it into three
  parts: the bar (look, world, feel, camera), platforms (phone, phone
  HUD, desktop) and how to build. It mapped each of Jake's 13 intents
  to where it ended up, so nothing was lost.
- Jake kept the hype: "absolutely amazing" in the opening and "a AAA
  game" in the done line, as in Cratefall's brief, which worked.
- "Commit early and often", with no push. The clean rooms are local
  folders with no remote (D34).
- The eight zones' READMEs are restamped from the one file.
