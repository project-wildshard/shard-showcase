# First rival before the full roster
Fetch Gate Sentry and the starting weapon concurrently, then load a new rival only on selection. Completed rivals are cached for rematches. While a new model is requested the previous fight stays intact and combat time pauses; a failed request leaves Next available for retry.

In three cache-disabled desktop Chromium runs of each revision, a local portrait session throttled to 450,000 B/s and 80 ms latency reached the first observed touch movement at medians of 7,953 ms eager and 3,750 ms on demand. Before that touch, requests dropped from 16 rival GLBs to one. The startup check also injected one temporary 503 for the next rival, verified the current fight stayed mounted, then loaded the next rival on retry. This is not a physical phone or CDN timing.
