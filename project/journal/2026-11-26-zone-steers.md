# Jake's steers on the eight descriptions

A run of small steers from Jake, applied to every zone so they stay
one family.

- "In the zone" now opens by saying the list is ideas to start from,
  to get a feeling for what to build, so the builder doesn't read it
  as a spec.
- Enemies opens "the enemies should include ..., and more". Where the
  new drafts named no kinds (Signal Dunes, Brasscap, Driftwood, Sky
  Reach, Mossgate, Pine Hollow) I took them from the old detailed
  drafts, minus the named elites.
- Nalati must look like the real places Jake named (the Nalati and
  Sky Grasslands, Snow Lotus and Panlong valleys), and it gains a
  Features section: horse racing, mounted combat, and enemies worthy
  of it.
