# Eight zone starter packs

ZC1 is built. Two Opus lanes each wrote four zones into
`~/projects/game-demos/<slug>-clean-room/`: a git-init folder with the
brief, a 120-line `ZONE-DESCRIPTION.md` and an empty `concept/`. No
Fable was run; Jake starts each session himself (D34). Copies sit in
`docs/plans/cleanroom-saga/support/zones/<slug>/` with a SOURCES file
naming what each description was taken from, reflowed to 72 columns
(the originals stay as written).

- Signal Dunes, the pilot, goes to level 15 and gains a waystation hub
  and a cistern dungeon. Brasscap gets Jake's looping train.
- The lanes made a few calls Jake should check: human raider factions
  in Dunes and Sky Reach, a hatchet in Pine Hollow (was ranged only),
  the Golden King over Jel Ata as Nalati's main boss, Nine Dragon to
  level 20, and some invented NPC names. They are listed in the review
  page with the art.
