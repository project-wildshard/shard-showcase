# Matched wet and dry West Plaza paving

The previous plaza study changes the light. This one fixes the
light, 1.7 m camera, board, shop and three lanterns, and changes
only the paving finish and visible pool overlays. Warm reflections
on the damp stones are easier to distinguish from the dark
pools when comparing the two matching views.

The exact tracked paving kit stays unchanged. The staging script
creates object-local wet material overrides so it can return to
the original dry material in the same setup. Four irregular pool
surfaces sit 2.5 mm above each footprint's highest sampled point.
The Blender source pins five donor SHA-256 hashes and checks
the camera, light, and object transforms across both states.
It writes the floor sample ranges and overlay digest to a receipt.

```sh
blender -b -t 6 --factory-startup --python-exit-code 1 \
  --python scripts/blender/showcase-studies/plaza_wet_surface.py -- /tmp/exact-plaza-wet
```

The overlay reimports as four meshes, 960 triangles, and 31,564 B.
It includes three opaque finish zones and optional
`KHR_materials_clearcoat`; it is not a refractive water system.
Place it in the staged plaza's local coordinates, not by copying
the offset into a different native scene. No donor meshes, lights
or wet paver duplicates in the GLB. No automatic weather switch,
surface friction, splash simulation, or mobile runtime proof.
