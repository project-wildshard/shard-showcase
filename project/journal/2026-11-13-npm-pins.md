# Pins from npm (NPM-PUBLISH NP8)

Engine, the sdk and shard-format now install from npm instead of
github tag specs. They were still on the very first tags (engine and
sharddev v0.1.0, format v0.4.2), so this is a long jump: engine
`0.1.18`, `@wildshard/sharddev` as `npm:@wildshard/sdk@0.2.12`,
`@wildshard/format` as `npm:@wildshard/shard-format@0.4.9`, exact.

The `packageExtensions` patch for `@wildshard/engine@0.1.0` is gone,
because engine has declared its peers since 0.1.17.
`assert-store-layout.mjs`, `pnpm check`, `test:shards` and
`build:shards` pass. Showcase builds no shard folder today, so
`build:shards` reports 0.
