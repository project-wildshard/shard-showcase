# W3a · Make the existing Six Dummies run visible on the existing board

The six fixtures and the board already existed in separate studies. The
new adapter consumes the unchanged native hit receipt rather than inventing
a score or rebuilding a prop. The three scripted routes reach the same
1,309-tick yard time (21.82 s). The board stays blank before a completed
run, carries the lowest verified fixture time through a serialization round
trip, and leaves Lanes and Rifle unset. No grade, competition target or
game release is implied by the scripted time.

The fixture rejects incomplete and malformed runs. Slower/faster values
are synthetic controls to prove min/last behavior. See the [replay
recipe](../../demos/native-range-record/README.md) and [receipt](../layouts/w3a-range-record-replay.json).
No changes to the timer mesh, record face download, equipment loan,
live scoring host, save format or iPhone build.
