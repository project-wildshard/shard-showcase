# Native Mite calibration draft

The editable staging recipe points at the exact installed SDK 0.4.12
template, adds the committed 386-triangle skin, and selects the native iron
sword for the initial loadout. Its format 0.43.0 validator checked the
hashes, rig, clip list, materials and native asset budget. The CLI built and
statically validated the format 2 product; the draft still reports library
and tile advisories and no execution samples in the static report. No
generated template, packaged product, cache or third-party source copy is
committed. This is not the live showcase game.
