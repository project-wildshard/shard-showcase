- The method is iteration: implement many ideas, and generalise the engine with each one.
- The hard constraint stands: other people upload content, Jake's server runs it, and it is never free JavaScript or TypeScript.
- The author's loop stands: one hour for a clean-room three.js prototype, a second hour to add the MMO primitives from the SDK.
